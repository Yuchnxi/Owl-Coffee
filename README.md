# Owl Coffee

Owl Coffee 是一套面向咖啡门店经营的数字化项目，首版目标是完成“后台维护商品与库存 -> 小程序点单 -> 模拟支付 -> 后台处理订单 -> 官网展示品牌与菜单”的可演示闭环。

项目定位为真实商用项目，当前版本为 v1 MVP 规划。

## 首版范围

- 单店经营
- 到店自提
- 模拟支付
- 后台优先
- 官网只做品牌展示，不做在线交易
- 小程序作为用户点单入口

首版不包含多门店经营、加盟商管理、真实微信支付、官网在线交易、外送配送、会员等级、积分、余额等复杂能力。

## 产品组成

| 产品 | 首版定位 | 说明 |
| --- | --- | --- |
| 后台系统 | 经营管理核心 | 管理商品、订单、用户、库存、营销和系统配置 |
| 小程序 | 用户点单入口 | 支持商品浏览、购物车、下单、模拟支付和订单查看 |
| 官网 | 品牌展示入口 | 展示品牌、菜单、门店和联系方式 |
| 服务端 | 数据与接口支撑 | 提供三端接口和业务逻辑 |

## 技术栈

| 端 | 技术栈 |
| --- | --- |
| 后台系统 | Vue 3 + Vite + Element Plus + Pinia + JavaScript |
| 官网 | Vue 3 + Vite + Tailwind CSS + JavaScript |
| 小程序 | 微信原生小程序 |
| 服务端 | Node.js + Egg.js + MySQL |

包管理工具统一使用 `pnpm`。

## 核心流程

```text
后台维护商品和 SKU
-> 小程序 / 官网展示上架商品
-> 小程序加入购物车并提交订单
-> 模拟支付成功后扣减库存并生成取餐码
-> 后台处理订单状态
-> 小程序查看订单状态
```

## 开发约束

- 全项目遵循 KISS 原则，非必要不做过度设计。
- 文档、注释、提交信息和 PR 描述使用中文。
- 代码标识使用英文，JavaScript 变量和函数使用小驼峰。
- 全项目统一使用 JavaScript，不新增 TypeScript 文件。
- 接口字段使用 `camelCase`，数据库字段使用 `snake_case`。
- 资源 ID 使用带业务前缀的 `nanoid` 字符串。
- 删除类能力默认使用软删除。
- 缺失真实资料时统一标记为“待补充”，不要编造商品、门店、联系方式、小程序二维码或支付配置。

更多规则见 [AGENTS.md](AGENTS.md)。
